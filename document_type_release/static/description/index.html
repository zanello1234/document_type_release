🎯 Overview

Document Type Release extends the Latin American localization to provide administrators with complete control over document type availability. Overcome default restrictions and manage your document types with ease.

💡 Why This Module?

In Latin American countries, document types are subject to strict AFIP responsibility and letter restrictions. While essential for compliance, these restrictions can limit flexibility in testing, migration, and special business scenarios. This module provides the tools to manage these situations effectively.

✨ Key Features

🔓

Release Documents

Activate or deactivate any document type regardless of its default state.

⚡

Force Availability

Make documents available bypassing letter and AFIP responsibility restrictions.

📋

Bulk Operations

Perform mass activate, deactivate, or toggle operations on multiple documents.

🔍

Advanced Filters

Filter by active status, forced availability, and group by country or type.

🔔

User Notifications

Visual confirmation messages for all actions performed on document types.

🔗

Invoice Integration

Forced documents automatically appear in invoice document type selection.

📖 How to Use

Accessing the Module

Navigate to Configuration

Go to Accounting → Configuration → Release Document Types

View All Documents

See all document types (active and inactive) with their current status

Manage Documents

Use toggles for individual changes or select multiple for bulk actions

Available Actions

Action Description
Activate Documents Enable selected inactive document types
Deactivate Documents Disable selected active document types
Toggle Active State Switch the state of each selected document
Force Availability Make documents available regardless of AFIP restrictions
Remove Forced Availability Restore normal restriction behavior
