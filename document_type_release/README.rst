This module extends the Latin American localization to provide flexible management
of document types that may be restricted by default in Odoo's LATAM invoice document system.

.. contents::
   :local:

Description
===========

In Latin American countries, particularly Argentina, document types for invoicing are 
subject to specific restrictions based on AFIP responsibility categories and letter 
assignments. While these restrictions are essential for compliance, there are scenarios 
where administrators need more flexibility:

* **Testing environments**: Access to all document types for comprehensive testing
* **Migration processes**: Temporary access during data migration
* **Special business cases**: Unique scenarios requiring non-standard document availability
* **Administrative control**: Centralized management of document type accessibility

This module solves these challenges by providing tools to:

1. **Release (activate/deactivate)** document types regardless of their default state
2. **Force availability** of specific document types, bypassing letter and responsibility restrictions
3. **Perform bulk operations** on multiple document types simultaneously

Features
========

Document Type Management
------------------------

* **Activate Documents**: Enable inactive document types
* **Deactivate Documents**: Disable active document types  
* **Toggle Active State**: Switch the active state of selected documents
* **Force Availability**: Make document types available regardless of AFIP restrictions
* **Remove Forced Availability**: Restore normal restriction behavior

Enhanced User Interface
-----------------------

* **Complete Document List**: View all document types (active and inactive) in one place
* **Boolean Toggles**: Quick inline editing of active and force_available fields
* **Advanced Filters**: 
  - Filter by Active/Inactive status
  - Filter by Forced Availability
  - Show all documents
* **Grouping Options**:
  - Group by Country
  - Group by Internal Type (Invoice, Credit Note, Debit Note)
  - Group by Active State
* **Bulk Actions**: Server actions available from the list view for mass operations
* **User Notifications**: Visual confirmation messages for all actions

Invoice Integration
-------------------

When a document type has "Force Availability" enabled:

* It will appear in the document type selection on invoices
* It bypasses the standard letter/responsibility filtering
* It respects the internal type (invoice, credit_note, debit_note) context

Usage
=====

Accessing the Module
--------------------

1. Navigate to **Accounting > Configuration > Release Document Types**
2. The view displays all document types with their current status

Activating/Deactivating Documents
---------------------------------

**Single Document:**

1. Find the document type in the list
2. Click the toggle in the "Active" column to change its state

**Multiple Documents:**

1. Select multiple documents using checkboxes
2. Click **Action** button
3. Choose one of:
   
   - **Activate Documents**: Enable all selected
   - **Deactivate Documents**: Disable all selected
   - **Toggle Active State**: Switch the state of each selected document

Forcing Document Availability
-----------------------------

When you need a document type available regardless of AFIP restrictions:

1. Select the document type(s)
2. Click **Action > Force Availability**
3. The document will now appear in invoice document type selection

To remove forced availability:

1. Select the document type(s)
2. Click **Action > Remove Forced Availability**
3. Normal restriction rules will apply again

Using Filters and Groups
------------------------

**Filters:**

* **Active**: Show only active document types
* **Inactive**: Show only inactive document types
* **Forced Availability**: Show documents with forced availability
* **All**: Show all documents regardless of status

**Groups:**

* **Country**: Group documents by their associated country
* **Internal Type**: Group by invoice, credit_note, debit_note, etc.
* **State**: Group by active/inactive status

Configuration
=============

No additional configuration is required. The module works out of the box with the
standard Latin American localization modules.

Prerequisites
-------------

Ensure the following modules are installed:

* ``account`` - Odoo Accounting
* ``l10n_latam_invoice_document`` - LATAM Invoice Documents

Recommended (for full functionality):

* ``l10n_ar`` - Argentinian Localization (for AFIP integration)
